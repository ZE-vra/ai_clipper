# Background music assets

By default, the pipeline scans `C:\\Editing_Assets\\Background_Music`. Place music you are licensed to use there, optionally organized into these mood folders:

- `assets/music/tension/`
- `assets/music/motivational/`
- `assets/music/energetic/`
- `assets/music/emotional/`
- `assets/music/corporate/`
- `assets/music/neutral/`

Supported formats: MP3, WAV, M4A, AAC, FLAC, and OGG.

The pipeline selects a track from the folder that best matches the clip context, loops it as needed, automatically ducks it under speech, and applies final loudness/true-peak mastering.

Only add music for which you have the necessary rights to use in generated videos.
